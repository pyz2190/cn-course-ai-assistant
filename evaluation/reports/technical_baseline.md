## 一、这份报告是什么、不是什么

**是：** 「问答库 → RAG 适配器 → 回答与引用」这条链路的可执行性验证，
以及语料覆盖面的实测证据。用于给人工交叉评审提供依据。

**不是：** 正式评测基线。正式基线只接受经人工交叉评审 `approved` 的标注
（见 [`review_workflow.md`](../review_workflow.md)），由
`scripts/run_evaluation_pipeline.py` 执行，产出 `baseline.md`。
本报告绕过了评审门禁，**不构成质量结论，也不构成验收依据**。

## 三、结果分析

### 3.1 两个正面结论

1. **链路完整可执行。** 30 题全部跑通，0 异常。C 的问答库、
   D 的 `InProcessRagAdapter` 与 RAG 服务之间的对接是通的。
2. **标注数据完整。** 30 条标注的 `expected_citations` 全部能在语料中
   解析到真实 Chunk，没有悬空引用。这是交叉评审可以直接开始的前提。

### 3.2 命中率 53% 的原因：语料覆盖面，不是检索质量

8 道安全拒答的题目是：

| 题号 | 类别 | 主题 |
|---|---|---|
| QA-CONCEPT-005 | 概念辨析 | 边缘计算负载均衡的时延与故障切换权衡 |
| QA-ERROR-001 | 典型错误 | 智能家居地址冲突的排查顺序 |
| QA-ERROR-003 | 典型错误 | 抓包现象与配置片段矛盾时如何处理 |
| QA-ERROR-004 | 典型错误 | 单点故障的记录与方案修订 |
| QA-LAB-003 | 实验问题 | 智能家居实验交付物的组织方式 |
| QA-LAB-004 | 实验问题 | 边缘计算实验的目标设定与权衡评估 |
| QA-REVIEW-004 | 复习问题 | 边缘计算方案的审核检查点 |
| QA-REVIEW-005 | 复习问题 | Reno 与 BBR 案例比较的复核要点 |

这些是任务引擎六类任务（见 [D-008](../../docs/D-008-任务引擎设计方案.md)）衍生出的
**教学法与流程类问题**——边缘计算负载均衡、智能家居网络设计、
实验交付物的组织方法、排错证据的整理规范。

而现有 22 个 Chunk 全部是**教材第 2–5 章的章节内容与 2 个实验的操作步骤**，
没有任何一份资料讲解这些主题。

**因此系统返回"课程资料中没有足够证据"是正确行为**，
符合 [D-004](../../docs/d-rag/D-004-rag-technical-solution.md) 第 6 节的引用安全设计——
无证据即拒答，而不是编造。这 8 题反映的是语料缺口，不是系统缺陷。

另有 6 题返回了引用但未命中期望 Chunk（QA-LAB-002、QA-PROTOCOL-002、
QA-PROTOCOL-005、QA-TOOL-001、QA-TOOL-002、QA-TOOL-004），
它们检索到了主题相邻的教材 Chunk，但问的是操作流程而非教材知识点，
成因与上面 8 题相同。

### 3.3 正确的改进方向

**补齐资料，而不是调低检索阈值。**

放宽 `min_retrieval_score` 或取消引用约束确实能把命中率做高，
但那是用幻觉换数字——正好违背本项目要解决的问题。

需要补充的资料类别（对应
[D-003](../../docs/D-003-知识库与问答库建设方案.md) 第二节清单）：

- **S4 视频字幕**：课堂讲解口径，需 Canvas Caption 通道（D-002 P4）
- **任务指导书类资料**：创新挑战与项目实践任务的方法论说明，需课程组编写
- **实验交付物规范与评分标准**：实验类问题的依据
- **S1–S3 的真实内容**：当前 22 个 Chunk 全是 mock 样例

## 四、下一步

```text
1. 课程组提供真实课程资料，补齐 3.3 指出的类别   ← 最大阻塞
2. 按 D-003 第三节流程完成授权审查与审校入库
3. 交叉评审把 ≥15 条标注推到 approved
4. python scripts/run_evaluation_pipeline.py sync
5. python scripts/run_evaluation_pipeline.py evaluate
6. 产出正式 baseline.md，替代本报告作为质量依据
```

第 3 步是人工流程，**不能由工具或自动化代替**：
`approved` 需要真实的 `reviewer` 与 `reviewed_at`，
且出题人不能评审自己的题目。
